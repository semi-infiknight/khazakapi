The Kazakh API catalogue — government open data (data.egov.kz, stat.gov.kz, NBK, Kazhydromet) plus curated commercial APIs — is available as a public REST API and a remote MCP server. Both are read-only, authless, and CORS-open. Base URL: http://localhost:8787 (dev) or your deployment host.

REST API

Browse and test the Kazakh API itself with a modern reference UI (Scalar — Postman-style layout, code snippets, try-it-out) or import into your own tools.

Catalogue APIs (1,400+ providers)

Each entry in the directory has its own API tester on the detail page — structured parameters, auth fields, response tabs — similar to Postman/Swagger per endpoint. Provider docs (Postman, Redoc, Swagger) are linked where available.

MCP server

Remote MCP at /mcp — tools: search_kz_apis, get_kz_api, list_api_categories. Step-by-step setup for Claude, Cursor, ChatGPT, and more: /mcp (setup page in the browser; JSON for MCP clients).

Tiers & honesty

open entries are free — snippets work where no auth is required. commercial entries (Kaspi, 2GIS, Halyk…) require provider onboarding. data.egov.kz datasets need a free API key from the developer cabinet.
